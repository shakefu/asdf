asdfマルチランタイム
バージョンマネージャ

1つのツールですべてのランタイムのバージョンを管理しましょう!

はじめよう
asdfってなに?
GitHubをみる
🎉

単一ツール

単体のCLIツールとコマンドインターフェースで、各プロジェクトのランタイムを管理できます。

🔌

プラグイン

既存ランタイム・ツールを使用した大規模なエコシステムです。必要に応じて新しいツールをサポートできるシンプルなAPIを用意しています!

⏮

後方互換性

.nvmrc、.node-version、.ruby-versionといった既存構成ファイルから、スムーズに移行できます!

📄

単一の構成ファイル

.tool-versionsを使用すると、すべてのツール、ランタイム、およびそれらのバージョンを、共有された単一の場所で管理できます。

🐚

シェル

Bash、ZSH、Fish、およびElvishをサポートし、コマンド補完にも対応しています。

🤖

GitHub Actions

CI/CDワークフローで、.tool-versionsをインストールし利用するためのGitHub Actionを提供しています。
